# Summit SEO

A readable dark SEO workspace inspired by [RankSteward](https://ranksteward.com), built with the **Unison programming language**. The HTTP server, HTML analysis, scoring, and JSON responses run in Unison. HTML/CSS and dependency-free JavaScript render the browser interface.

The shared app targets **Unison Cloud's Free plan**, with actual HTML audits running in Unison. Each visitor has a separate browser-local workspace. The Free plan includes 5,000 requests/month, up to five services, and services deactivate after three weeks; see [current pricing](https://www.unison.cloud/pricing/).

Cloud assets are embedded into Unison definitions using `node scripts/build-cloud-assets.mjs`. In UCM, install `@unison/cloud/releases/27.3.1`. Load and update `src/cloud-assets.u` and `src/cloud.u` after the local app, then run `summit.cloud.deploy`. The deploy function uses a dedicated `summit-seo-demo` environment and names the service `summit-seo`.

An optional static preview build remains available through `node scripts/build-demo.mjs`; it is not the Cloud deployment. Its labeled sample is generated by the local Unison engine using `node scripts/generate-sample.mjs`.

## Open the app

From this directory in PowerShell:

```powershell
.\Start.ps1
```

Visit **http://127.0.0.1:4174**. The server binds to your computer's loopback interface. If the app is already running, open the URL directly. Stop its terminal process with Ctrl+C.

## What works

- Overview with an explicitly labeled demo workspace, charts, and prioritized opportunities.
- Import a Search Console **Pages CSV** with Page (or Top pages), Clicks, Impressions, CTR, and Position columns. Imported totals replace sample metrics. Page-only data does not fabricate historical trends.
- Search and filter opportunities, edit proposed titles and descriptions, preview search snippets, save local approvals/dismissals, and undo decisions.
- Paste/upload UTF-8 HTML (under 500 KB) for a real Unison audit: page title, description, H1 count, canonical, language, robots directives, and image alt attributes.
- Export a JSON workspace report. Workspace data and review history persist in this browser's local storage.
- Responsive mobile navigation and keyboard-accessible review controls.

## Boundaries of this version

This is a local first version, not a connected publishing service. Search Console, WordPress and GitHub are **not connected**. Approvals save drafts locally; they do not publish or change another website. Imported metrics are not live synced. Initial metrics and recommendations are illustrative sample data.

Audit the HTML source you supply; this version does not crawl URLs, execute JavaScript, inspect HTTP headers/robots.txt, measure speed, or verify canonical destinations. The lightweight HTML scanner supports quoted/unquoted attributes, casing, comments and script/style content; it is not a complete browser HTML parser. Review results against the source for malformed markup. Title/description lengths are editorial guidelines. The 0–100 checklist score weights each of seven checks equally (pass = 2, warning = 1, fail = 0), and is not a Google ranking prediction. Empty alt attributes are valid for decorative images.

Local browser storage is specific to the hostname (use 127.0.0.1 consistently) and can be cleared by the browser. Export important work.

## Rebuild with UCM

Requires [Unison UCM](https://www.unison-lang.org/docs/install-instructions/) 1.3 and the public `@unison/http/releases/8.0.0` library. No Node server or frontend build is required.

The current compiled artifact is `build/summit.uc`. Definitions are also saved in the local UCM project `summit-seo/main`.

Start UCM from this directory (`chcp 65001` first on Windows). For a new installation:

```text
project.create summit-seo
lib.install @unison/http/releases/8.0.0
```

For the existing project, use `project.switch summit-seo/main`. Load and compile in this order:

```text
load src/audit.u
update
load src/audit-tests.u
update
load src/server.u
update
test summit.tests
compile summit.main build/summit
```

Create the `build` directory first if needed. The compile command writes `build/summit.uc`. After rebuilding, restart the application. Static browser assets are read on each request; reload the browser after editing them.

## Verification

The pure audit tests run using `test summit.tests` in UCM. With the application running, Node 22+ can run the HTTP integration tests:

```powershell
node --test tests/http.test.mjs
node --check web/app.js
```

## Source map

- `src/audit.u`: HTML scanning and seven audit rules.
- `src/audit-tests.u`: pure Unison regression tests.
- `src/server.u`: bounded API, JSON encoding, loopback HTTP server and fixed static asset routes.
- `web/`: dashboard presentation, local review state, CSV import and exports.
- `tests/http.test.mjs`: actual HTTP requests against the running Unison process.
